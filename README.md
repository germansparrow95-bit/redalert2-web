# Red Alert Web — 网页版「红警风格」遭遇战

一个**纯静态、零依赖**的浏览器即时战略游戏：等距视角战场、矿石经济、电力系统、科技树、
战争迷雾、雷达小地图，以及一个会自己造基地、扩张、防守和成波进攻的电脑对手。

全部美术与音效都由代码在运行时生成（程序化绘制 / Web Audio 合成），项目里**没有任何
第三方图片、音频或引擎文件**，也没有使用任何商业游戏的素材。

界面与语音默认**全中文**：所有播报（基地遭袭、电力不足、单位应答、建造完成……）都通过
浏览器的中文语音引擎朗读，可在设置里切换中英文界面、单独调节语音音量或关闭语音。

## 1. 快速开始（本地运行）

### 方式 A：直接双击打开（最简单）

双击 `index.html` 即可。所有脚本都是普通 `<script>`，不依赖服务器，`file://` 下同样能玩。

### 方式 B：本地服务器（推荐）

```bash
node tools/serve.mjs          # 默认 http://localhost:8080/
node tools/serve.mjs 9000     # 指定端口
```

### 方式 C：单文件构建版

```bash
node tools/build.mjs          # 生成 dist/index.html（约 300 kB，全部内联）
```

`dist/index.html` 单文件即可运行、即可上传，非常适合交作业。

## 3. 分享「同一张地图」的链接

游戏把整场战斗压缩成 URL 参数，老师点开就是你指定的那局：

```
https://你的域名/?seed=4242&autostart=1&faction=soviet&difficulty=normal&opponents=1
```

| 参数 | 说明 | 取值 |
| --- | --- | --- |
| `seed` | 地图种子（决定地形、矿区、出生点） | 数字或任意文字（会哈希） |
| `autostart` | `1` = 打开网页立刻开打，跳过主菜单 | `0` / `1` |
| `faction` | 你的阵营 | `allied` / `soviet` |
| `color` | 你的颜色 | `0`–`7` |
| `difficulty` | 电脑难度 | `easy` / `normal` / `hard` |
| `size` | 地图尺寸 | `small` / `medium` / `large` |
| `opponents` | 电脑玩家数量 | `1`–`3` |
| `enemy` | 电脑阵营 | `allied` / `soviet` / `mixed` |
| `credits` | 初始资金 | 数字 |
| `start` | 初始基地 | `mcv` / `standard` / `quick` |
| `shortgame` | `1` = 摧毁全部建造厂即判定胜负 | `0` / `1` |
| `fog` | 战争迷雾 | `0` / `1` |

打完一局后，结算界面会直接给出**这一局的分享链接**，可以复制进作业报告。

### 中文语音

* 覆盖场合：单位/建筑选中后的**指令应答**（步兵、坦克、矿车、工程师、飞行兵各有一套台词）、
  **基地警报**（遭到攻击、电力不足）、**建造播报**（单位就绪、建筑完成、需要放置位置）、
  **经济提示**（资金不足、没有精炼厂、矿区枯竭）、**战况播报**（单位晋升、占领成功、卫星上线）
  以及**胜负结算**。
* 台词全部是原创中文短句（例如「是，长官！」「锁定目标，开火！」「指挥官，基地遭到攻击！」），
  台词表在 [src/audio/voice.js](src/audio/voice.js) 的 `LINES` 里，改几行就能换成你自己的配音文本。
* 实现方式是浏览器的 `speechSynthesis`（`lang = zh-CN`），**不下载任何音频文件**；同一句话有
  多条随机变体，并且带节流与去重，不会连着念同一条。
* 如果电脑上没有装中文语音包，游戏会自动改用无线电提示音（而不是念英文），界面上的中文提示
  文字照常显示；设置里会给出提示。
* 设置 → 界面语言：中文 / English（默认中文）；语音可单独开关与调音量，并有「试听语音」按钮。

### 玩法要点

* **经济**：建造厂 → 电站 → 矿石精炼厂（附赠一辆采矿车）→ 兵营 / 战车工厂。
  采矿车会把矿石换成资金，靠近新矿脉再造一座精炼厂可以显著提高收入。
* **电力**：用电超过发电时，防御建筑会**停机**、建造速度减半。注意左侧 POWER 条。
* **放置**：建筑必须先建好，再点击图标放置，且必须**紧贴已有建筑**；矿石、水面、悬崖、
  岩石和单位所在格不能建造。
* **科技**：战车工厂 + 精炼厂 → 作战实验室，解锁重型坦克 / 激光坦克与高级防御。
* **经验**：击杀可让单位晋升（老兵 → 精英），伤害更高、装填更快、视野更远，并会自我修复。
* **工程师**：走进敌方建筑即可占领（保留 50% 生命值），是对付防守阵地的好办法。
* **胜负**：默认「速战」规则下，摧毁对方全部建造厂即获胜；关闭后必须推平整个基地。
  25 分钟后会触发「卫星上线」，迷雾全开，避免长期僵持。

## 5. 代码结构（便于阅读与答辩）

```
index.html            页面骨架（侧边栏 DOM）
styles.css            红警风格的金属面板 / 按钮 / 菜单样式
src/core/             纯逻辑模拟，不依赖 DOM，可在 Node 里跑
  util.js             数学、确定性随机数、二叉堆、LRU 缓存
  rules.js            装甲/弹头表、单位与建筑数据、阵营科技树、难度参数
  map.js              程序化地图生成（对称矿区、出生点校验、可通行性验证）
  pathfind.js         A* 寻路 + 视线平滑 + 缓存（带预算，避免卡帧）
  sim.js              实体、指令、移动、战斗、经济、迷雾、生产队列、胜负判定
  ai.js               电脑对手：建造顺序、扩张、防御、集结与成波进攻
src/render/           渲染层
  art.js              全部程序化美术（等距盒体、炮塔、地形、矿石、图标）
  iso.js              等距投影换算
  renderer.js         战场绘制（地形 / 单位 / 特效 / 迷雾 / 选择框）
  minimap.js          菱形雷达小地图
src/ui/
  i18n.js             中英双语字符串表 + 单位/建筑/武器中文译名
  hud.js              侧边栏：资金、电力、建造按钮、选择信息、警报
  input.js            鼠标 / 键盘、选择、指令、放置、编队、热键
  screens.js          主菜单 / 遭遇战设置 / 选项 / 帮助 / 暂停 / 结算
src/audio/
  sfx.js              Web Audio 程序化音效（爆炸、射击、确认、警报……）
  voice.js            中文语音播报（浏览器语音引擎 + 无线电提示音兜底）
tools/                开发与交付工具
  serve.mjs           本地静态服务器
  build.mjs           打包成单文件 dist/index.html
  screenshot.mjs      无浏览器环境下渲染 PNG（软件 Canvas 实现）
  canvas-shim.mjs     极简 Canvas2D 软件实现（仅用于截图与测试）
  dom-shim.mjs        极简 DOM 实现（仅用于 UI 测试）
  load-core.mjs       在 Node 中加载核心逻辑
  png.mjs             PNG 编码（仅用于截图输出）
tests/                自动化测试（node --test）
deploy/               Netlify / Vercel / GitHub Pages 配置
```

### 设计要点

* **模拟与渲染分离**：`src/core` 完全不碰 DOM，因此可以在 Node 里跑完整对局做测试。
* **确定性**：模拟只使用带种子的伪随机数（mulberry32），相同种子 → 完全相同的战场，
  也因此可以做回放式分享链接和一致性测试。
* **性能**：固定 30 Hz 逻辑步长 + 空间网格加速（查询、分离、溅射）；
  地形贴图预渲染缓存；迷雾按多边形批量填充。4 玩家大混战实测约 2 ms/tick。
* **健壮性**：矿车被建筑围死、寻路失败、目标中途死亡、工厂出口被占等情况都有兜底逻辑
  （矿点黑名单、卡住重寻路 / 微位移脱困、生产出口拥挤度评分等）。

以及性能预算（每 tick < 8 ms）。

UI 测试会解析真实的 `index.html`，在极简 DOM 上跑通：启动主菜单 → 遭遇战设置 →

Esc 暂停 / 继续 → 完整对局结算 → URL 参数直开 → **单文件构建版也能正常启动**。

以及中英文切换后界面标签会跟着变。

## 7. 关于素材与版权

* 本项目**不使用**任何《红色警戒 2》或其他商业游戏的文件、贴图、模型、音乐或语音。
* 所有画面均为 `src/render/art.js` 用 Canvas 2D 程序化绘制；所有声音均为
  `src/audio/sfx.js` 用 Web Audio 振荡器与噪声实时合成；语音由浏览器自带的中文语音引擎
  朗读 `src/audio/voice.js` 里**自己写的**台词文本，项目不含任何录音文件。
* 代码与美术均可自由用于课程作业与展示。游戏玩法类型（等距 RTS、矿石经济、电力、
  科技树）属于通用玩法设计，不构成对具体作品的复制。
* 如果你确实想换成自己手绘或获得授权的素材，只需替换 `src/render/art.js` 中的
  `unitSprite / buildingSprite / tileSprite / iconSprite` 四个函数，
  逻辑层完全不需要改动。

## 9. 已知限制

* 仅支持**人机遭遇战**，不含联网对战；电脑对手使用与玩家完全相同的接口（不额外作弊，
  难度只影响它的思考频率与生产速度）。
* 没有海军、超级武器和地形高低差；空军只有盟军火箭飞行兵，防空由爱国者 / 防空炮 /
  步兵导弹承担。
* 中文语音依赖系统/浏览器是否装有中文语音包（Windows 的 Edge/Chrome 一般自带微软中文语音）；
  没有时自动用提示音代替。语音是合成音，语气肯定比不上真人配音。
